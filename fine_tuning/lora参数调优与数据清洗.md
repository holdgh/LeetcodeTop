# 二选一：LoRA参数调优技巧+数据清洗实操步骤（极简实操单）
## 版本1：LoRA参数调优核心技巧（落地向，直接复用）
### 一、核心参数优先级（调参按此顺序，一次只改1个）
1. 学习率（第一敏感参数）＞ r值（低秩维度）＞ batch_size/梯度累加 ＞ dropout/权重衰减
2. 所有参数先固定「经验基线值」跑通流程，再针对性调优

### 二、核心参数经验基线（直接用，90%场景适配）
| 参数          | 分类/简单任务 | 生成/复杂问答任务 | 关键说明                     |
|---------------|---------------|------------------|------------------------------|
| r（低秩维度） | 8~16          | 16~32            | 越大拟合越强，易过拟合，＞32无意义 |
| lora_alpha    | r值的2倍      | r值的2倍         | 固定配比，无需单独调         |
| target_modules | ["q_proj","v_proj"] | ["q_proj","v_proj"] | 生成类模型通用最优层，理解类可加"k_proj" |
| lora_dropout  | 0.05          | 0.05~0.1         | 仅防过拟合，无需调太高       |
| 学习率        | 2e-4          | 3e-4~5e-4        | LoRA专用，远高于全参数微调   |
| batch_size    | 2~4           | 4~8              | 显存不够用梯度累加补足       |
| epochs        | 3~5           | 3~5              | 超过5轮必过拟合              |

### 三、针对性调优方案（对症下藥，不用试错）
| 问题现象                | 核心调优动作                                  |
|-------------------------|-----------------------------------------------|
| 欠拟合（训/验证集都差） | 1. 学习率提10%~20% 2. r值上调一档 3. 加1~2轮epochs |
| 过拟合（训好/验证差）   | 1. 学习率降10%~20% 2. r值下调一档 3. dropout提至0.1 4. 加weight_decay=0.01~0.05 |
| Loss波动大              | 1. 减小学习率 2. 增大batch_size/梯度累加步数 3. 开学习率预热 |
| 生成内容重复/逻辑乱     | 1. 降低r值 2. 清洗训练数据去重 3. 生成时调低temperature=0.7 |

### 四、调优避坑3条铁律
1. 绝不同时改多个参数：改1个跑一轮，明确参数影响
2. 优先调学习率/r值：80%的效果问题靠这两个解决
3. 量化训练必开：load_in_8bit=True不影响调参逻辑，仅省显存

## 版本2：数据清洗实操步骤（全流程，可落地）
### 一、核心原则
质量＞数量，清洗后样本需满足：无重复、无噪声、标签准、格式统一、分布均衡

### 二、分步实操（按顺序执行，每步有判断标准）
| 步骤         | 实操方法                                                                 | 工具/阈值                | 验收标准                     |
|--------------|--------------------------------------------------------------------------|--------------------------|------------------------------|
| 1. 数据筛选   | 保留与任务强相关样本，删除无关/低质样本（如通用闲聊凑数样本）| 人工初筛+关键词过滤      | 样本100%匹配目标任务场景     |
| 2. 去重       | 1. 完全重复：按文本MD5去重 2. 高度相似：计算文本相似度去重               | 相似度阈值≥90%（jieba+余弦相似度） | 无重复/高度相似样本          |
| 3. 去噪       | 1. 删乱码/错别字/无效符号 2. 删逻辑混乱/答非所问样本 3. 截断超长无意义文本 | 人工校验+正则清洗        | 样本文本通顺、无无关信息     |
| 4. 标签校准   | 1. 检查标签准确性（分类/NER） 2. 平衡类别分布（单类占比≤80%）| sklearn计算类别占比      | 标签无错误，类别分布相对均衡 |
| 5. 格式标准化 | 统一样本格式（如指令微调：instruction+input+output），无格式歧义         | JSONL统一存储            | 所有样本字段完整、格式一致   |
| 6. 数据划分   | 按7:2:1分训练/验证/测试集，确保分布一致                                  | stratified_split分层划分 | 无数据泄露，各集分布与原数据一致 |
| 7. 数据增强（可选） | 小样本（＜500条）：同义词替换/回译/句子重排；生成类：模型扩写后人工校验 | 同义词词林/百度翻译API   | 增强样本质量不低于原样本     |

### 三、快速验收（5分钟检查）
1. 随机抽10%样本，人工看：无重复、无噪声、格式对、标签准
2. 统计类别分布：无极端不平衡（单类占比＜80%）
3. 测试集未参与训练/验证：无数据泄露
