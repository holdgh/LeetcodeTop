### 2. 数据准备（中文情感分类数据集）
#### （1）数据集说明
使用公开的「酒店评论情感分类数据集」，包含正向/负向两类样本，格式为`text + label`（label=0负向，label=1正向），你可替换为自己的数据集（需保证格式一致）。

#### （2）数据集加载与划分
```python
import pandas as pd
from sklearn.model_selection import train_test_split
from datasets import Dataset, DatasetDict

# 1. 加载示例数据集（替换为你的本地数据集路径）
# 示例数据集格式：csv文件，包含text（评论文本）、label（0/1）两列
df = pd.read_csv("hotel_comment.csv", encoding="utf-8")

# 2. 数据清洗（轻量去噪，适配分类任务）
import re
def clean_text(text):
    # 删特殊符号/乱码，保留中文
    text = re.sub(r"[^\u4e00-\u9fa5\s]", "", text)
    return text.strip()

df["text"] = df["text"].apply(clean_text)
df = df[df["text"].str.len() > 5]  # 保留有效文本（长度＞5）

# 3. 划分训练集/验证集/测试集（7:2:1）
train_df, rest_df = train_test_split(df, test_size=0.3, random_state=42, stratify=df["label"])
val_df, test_df = train_test_split(rest_df, test_size=1/3, random_state=42, stratify=rest_df["label"])

# 4. 转换为Hugging Face Dataset格式
train_dataset = Dataset.from_pandas(train_df)
val_dataset = Dataset.from_pandas(val_df)
test_dataset = Dataset.from_pandas(test_df)
dataset = DatasetDict({
    "train": train_dataset,
    "validation": val_dataset,
    "test": test_dataset
})
```

### 3. 数据预处理（适配all-MiniLM-L6-v2）
```python
from transformers import AutoTokenizer

# 1. 加载Tokenizer（all-MiniLM-L6-v2原生支持中文）
tokenizer = AutoTokenizer.from_pretrained("sentence-transformers/all-MiniLM-L6-v2")

# 2. 预处理函数（分类任务核心：编码文本+标签）
def preprocess_function(examples):
    # 编码文本：max_length=128（适配短文本分类）
    encoding = tokenizer(
        examples["text"],
        max_length=128,
        truncation=True,
        padding="max_length",
        return_tensors="pt"
    )
    # 标签转换为tensor（分类任务需int型）
    encoding["labels"] = examples["label"]
    return encoding

# 3. 批量预处理数据集
tokenized_dataset = dataset.map(
    preprocess_function,
    batched=True,
    remove_columns=dataset["train"].column_names  # 删除原始列，仅保留编码后数据
)

# 4. 设置数据集格式（适配PyTorch）
tokenized_dataset.set_format("torch", columns=["input_ids", "attention_mask", "labels"])
```

### 4. 加载模型（适配分类任务）
```python
from transformers import AutoModelForSequenceClassification

# 加载模型：num_labels=2（二分类），若多分类则修改为对应类别数
model = AutoModelForSequenceClassification.from_pretrained(
    "sentence-transformers/all-MiniLM-L6-v2",
    num_labels=2,  # 情感分类为二分类，根据你的任务调整
    problem_type="classification",  # 指定任务类型
    device_map="auto"  # 自动分配设备（CPU/GPU）
)

# 验证模型加载成功
print(f"模型可训练参数：{sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
# all-MiniLM-L6-v2全参数约80M，训练成本极低
```

### 5. 训练参数设置（Windows适配）
```python
from transformers import TrainingArguments, Trainer
import numpy as np
from sklearn.metrics import accuracy_score, f1_score

# 1. 定义评估指标（分类任务核心：准确率+F1值）
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    accuracy = accuracy_score(labels, predictions)
    f1 = f1_score(labels, predictions, average="weighted")
    return {"accuracy": accuracy, "f1": f1}

# 2. 训练参数（适配Windows CPU/低配N卡）
training_args = TrainingArguments(
    output_dir="./all-MiniLM-L6-v2-finetune",  # 结果保存路径
    per_device_train_batch_size=8,  # CPU可设4~8，GPU可设16~32
    per_device_eval_batch_size=8,
    num_train_epochs=5,  # 小模型5轮足够，避免过拟合
    learning_rate=2e-5,  # BERT类模型通用学习率
    logging_steps=10,  # 每10步打印日志
    evaluation_strategy="epoch",  # 每轮评估验证集
    save_strategy="epoch",  # 每轮保存模型
    load_best_model_at_end=True,  # 加载最优模型
    fp16=False,  # CPU禁用，GPU可设True
    weight_decay=0.01,  # 防过拟合
    warmup_ratio=0.1,  # 学习率预热
    metric_for_best_model="f1",  # 以F1值选最优模型
    greater_is_better=True  # F1值越高越好
)

# 3. 定义Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["validation"],
    compute_metrics=compute_metrics  # 评估指标
)
```

### 6. 启动训练
```python
# 开始微调（Windows CPU约30~60分钟，GPU约5~10分钟）
trainer.train()

# 保存最优模型
trainer.save_model("./best-model")
tokenizer.save_pretrained("./best-model")
```

### 7. 模型评估与推理
```python
# 1. 在测试集上评估最终效果
test_results = trainer.evaluate(tokenized_dataset["test"])
print("测试集评估结果：")
print(f"准确率：{test_results['eval_accuracy']:.4f}")
print(f"F1值：{test_results['eval_f1']:.4f}")

# 2. 推理示例（预测新文本的情感）
def predict(text):
    # 预处理文本
    inputs = tokenizer(
        text,
        max_length=128,
        truncation=True,
        padding="max_length",
        return_tensors="pt"
    ).to("cpu")  # 强制CPU（无GPU时）
    
    # 推理（关闭梯度计算，提升速度）
    model.eval()
    with torch.no_grad():
        outputs = model(**inputs)
        logits = outputs.logits
        prediction = torch.argmax(logits, dim=-1).item()
    
    # 映射标签
    label_map = {0: "负向", 1: "正向"}
    return label_map[prediction]

# 测试推理
test_text1 = "这家酒店环境太差了，卫生不干净，服务也很敷衍"
test_text2 = "酒店位置很好，房间宽敞明亮，服务人员很热情"
print(f"文本1预测结果：{predict(test_text1)}")  # 应输出：负向
print(f"文本2预测结果：{predict(test_text2)}")  # 应输出：正向
```

## 三、关键适配点说明（针对all-MiniLM-L6-v2）
### 1. 模型任务适配
all-MiniLM-L6-v2原生用于「句子嵌入」，微调为分类任务时需：
- 加载模型时指定`num_labels`（分类类别数）；
- 设置`problem_type="classification"`，确保模型输出分类logits而非嵌入向量。

### 2. 学习率选择
BERT类轻量模型的学习率建议在`1e-5 ~ 3e-5`之间，all-MiniLM-L6-v2用`2e-5`最优，过高易过拟合，过低学不动。

### 3. Windows硬件优化
- CPU训练：`per_device_train_batch_size`设为4~8，避免内存溢出；
- 关闭无关软件（浏览器/微信），释放CPU/内存资源；
- 若训练速度慢，可截取500条样本先练手，熟悉流程后再用全量数据。

## 四、任务扩展（替换为其他理解类任务）
### 1. 文本匹配/相似度计算
修改模型加载为回归任务（`num_labels=1`，`problem_type="regression"`），标签改为相似度分数（0~1），评估指标改为MAE/MSE。

### 2. 多分类任务
仅需修改`num_labels`为分类数（如3分类设`num_labels=3`），评估指标的`f1_score`改为`average="macro"`。

### 3. NER命名实体识别
需调整数据预处理（编码token级标签），模型加载为`AutoModelForTokenClassification`，其余逻辑基本一致。

## 五、常见问题与修复
### 问题1：Tokenizer编码中文时乱码
```python

    "sentence-transformers/all-MiniLM-L6-v2",
    use_fast=False,  # 禁用fast tokenizer，避免中文乱码
    encoding="utf-8"

```

### 问题2：训练时Loss为NaN
```python
# 修复：检查标签是否为int型，且无空值
df["label"] = df["label"].astype(int)
df = df.dropna(subset=["text", "label"])
```

### 问题3：模型预测结果全为一类（过拟合/欠拟合）
- 过拟合：减少epochs至3轮，增大`weight_decay`至0.05；
- 欠拟合：提升学习率至`3e-5`，增加训练样本量，或延长训练轮数。
