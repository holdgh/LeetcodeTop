常见的排序算法可以分为**比较类排序**和**非比较类排序**，以下是它们的分类、原理及实现要点：

---

### **一、比较类排序**
#### 1. **冒泡排序（Bubble Sort）**
- **原理**：依次比较相邻元素，将较大的元素交换到右侧，每一轮将当前未排序部分的最大值“冒泡”到末尾。
- **时间复杂度**：  
  - 最好情况（已有序）：O(n)  
  - 最坏/平均情况：O(n²)  
- **空间复杂度**：O(1)（原地排序）  
- **代码要点**：
  ```python
  def bubble_sort(arr):
      for i in range(len(arr)):
          for j in range(len(arr)-i-1):
              if arr[j] > arr[j+1]:
                  arr[j], arr[j+1] = arr[j+1], arr[j]
  ```

#### 2. **选择排序（Selection Sort）**
- **原理**：每次从未排序部分选择最小（或最大）元素，放到已排序部分的末尾。
- **时间复杂度**：O(n²)（始终需要比较所有未排序元素）  
- **空间复杂度**：O(1)  
- **代码要点**：
  ```python
  def selection_sort(arr):
      for i in range(len(arr)):
          min_idx = i
          for j in range(i+1, len(arr)):
              if arr[j] < arr[min_idx]:
                  min_idx = j
          arr[i], arr[min_idx] = arr[min_idx], arr[i]
  ```

#### 3. **插入排序（Insertion Sort）**
- **原理**：将未排序部分的元素逐个插入到已排序部分的正确位置。
- **时间复杂度**：  
  - 最好情况（已有序）：O(n)  
  - 最坏/平均情况：O(n²)  
- **空间复杂度**：O(1)  
- **代码要点**：
  ```python
  def insertion_sort(arr):
      for i in range(1, len(arr)):
          key = arr[i]
          j = i-1
          while j >=0 and key < arr[j]:
              arr[j+1] = arr[j]
              j -= 1
          arr[j+1] = key
  ```

#### 4. **快速排序（Quick Sort）**
- **原理**：分治法。选择一个基准（pivot），将数组分为小于基准和大于基准的两部分，递归排序子数组。
- **时间复杂度**：  
  - 最好/平均情况：O(n log n)  
  - 最坏情况（极端不平衡划分）：O(n²)  
- **空间复杂度**：O(log n)（递归栈空间）  
- **代码要点**：
  ```python
  def quick_sort(arr, low, high):
      if low < high:
          pivot_idx = partition(arr, low, high)
          quick_sort(arr, low, pivot_idx-1)
          quick_sort(arr, pivot_idx+1, high)
  
  def partition(arr, low, high):
      pivot = arr[high]
      i = low
      for j in range(low, high):
          if arr[j] < pivot:
              arr[i], arr[j] = arr[j], arr[i]
              i += 1
      arr[i], arr[high] = arr[high], arr[i]
      return i
  ```

#### 5. **归并排序（Merge Sort）**
- **原理**：分治法。将数组分为两半，分别排序后合并两个有序子数组。
- **时间复杂度**：O(n log n)（始终）  
- **空间复杂度**：O(n)（合并时需要临时数组）  
- **代码要点**：
  ```python
  def merge_sort(arr):
      if len(arr) > 1:
          mid = len(arr) // 2
          L, R = arr[:mid], arr[mid:]
          merge_sort(L)
          merge_sort(R)
          i = j = k = 0
          while i < len(L) and j < len(R):
              if L[i] < R[j]:
                  arr[k] = L[i]
                  i += 1
              else:
                  arr[k] = R[j]
                  j += 1
              k += 1
          while i < len(L):
              arr[k] = L[i]
              i += 1; k += 1
          while j < len(R):
              arr[k] = R[j]
              j += 1; k += 1
  ```

#### 6. **堆排序（Heap Sort）**
- **原理**：利用堆（通常是大顶堆）的性质，每次取出堆顶元素（最大值），调整堆结构。
- **时间复杂度**：O(n log n)（建堆 O(n)，调整堆 O(log n)）  
- **空间复杂度**：O(1)  
- **代码要点**：
  ```python
  def heapify(arr, n, i):
      largest = i
      l, r = 2*i+1, 2*i+2
      if l < n and arr[l] > arr[largest]:
          largest = l
      if r < n and arr[r] > arr[largest]:
          largest = r
      if largest != i:
          arr[i], arr[largest] = arr[largest], arr[i]
          heapify(arr, n, largest)
  
  def heap_sort(arr):
      n = len(arr)
      for i in range(n//2-1, -1, -1):  # 建堆
          heapify(arr, n, i)
      for i in range(n-1, 0, -1):     # 逐个提取
          arr[0], arr[i] = arr[i], arr[0]
          heapify(arr, i, 0)
  ```

---

### **二、非比较类排序**
#### 1. **计数排序（Counting Sort）**
- **原理**：统计每个元素的出现次数，按统计结果直接输出有序序列。  
- **适用条件**：元素范围较小（如 0~k）。  
- **时间复杂度**：O(n + k)（k 为元素范围）  
- **空间复杂度**：O(n + k)  

#### 2. **桶排序（Bucket Sort）**
- **原理**：将元素分到多个桶中，对每个桶单独排序后合并。  
- **适用条件**：数据均匀分布。  
- **时间复杂度**：  
  - 最好情况：O(n)  
  - 最坏情况：O(n²)（所有元素集中在一个桶）  

#### 3. **基数排序（Radix Sort）**
- **原理**：按位数从低位到高位依次排序（通常使用计数排序作为子过程）。  
- **适用条件**：元素为非负整数或固定位数的字符串。  
- **时间复杂度**：O(d(n + k))（d 为位数，k 为基数）  

---

### **三、总结**
| 排序算法     | 平均时间复杂度 | 空间复杂度 | 稳定性 |
|--------------|----------------|------------|--------|
| 冒泡排序     | O(n²)          | O(1)       | 稳定   |
| 选择排序     | O(n²)          | O(1)       | 不稳定 |
| 插入排序     | O(n²)          | O(1)       | 稳定   |
| 快速排序     | O(n log n)     | O(log n)   | 不稳定 |
| 归并排序     | O(n log n)     | O(n)       | 稳定   |
| 堆排序       | O(n log n)     | O(1)       | 不稳定 |
| 计数排序     | O(n + k)       | O(n + k)   | 稳定   |
| 桶排序       | O(n + k)       | O(n + k)   | 稳定   |
| 基数排序     | O(d(n + k))    | O(n + k)   | 稳定   |

**注**：  
- **稳定性**：相等元素的相对顺序在排序后是否保持不变。  
- **适用场景**：  
  - 小规模数据：插入排序（简单且稳定）。  
  - 大规模数据：快速排序（平均最优）或归并排序（稳定但需额外空间）。  
  - 非比较排序：适用于特定范围或结构的数据（如整数）。
