### **一、堆的定义**
**堆（Heap）** 是一种基于 **完全二叉树** 的特殊数据结构，满足以下性质：  
1. **结构性**：是一棵 **完全二叉树**（所有层除最后一层外均填满，最后一层从左到右填充）。  
2. **有序性**：  
   - **大顶堆（Max-Heap）**：每个父节点的值 **≥** 其子节点的值。  
   - **小顶堆（Min-Heap）**：每个父节点的值 **≤** 其子节点的值。  

---

### **二、堆的存储方式**
堆通常用 **数组** 实现，利用完全二叉树的性质，通过下标直接定位父子节点：  
- 父节点索引为 `i` 时：  
  - 左子节点索引：`2i + 1`  
  - 右子节点索引：`2i + 2`  
- 子节点索引为 `j` 时，父节点索引：`⌊(j-1)/2⌋`  

**示例**：  
```
数组表示：[10, 8, 9, 3, 5, 2, 7]
对应的完全二叉树：
        10
       /  \
      8    9
     / \  / \
    3  5 2   7
```

---

### **三、大顶堆的核心特点**
#### 1. **堆顶元素为最大值**
- 根节点（堆顶）是整个堆中的最大元素，但 **不保证其他层有序**。  
- **示例**：  
  ```
        20
       /  \
      15   10   ← 父节点值 ≥ 子节点值
     / \   /
    5  12 8
  ```

#### 2. **操作时间复杂度**
- **插入（Insert）**：O(log n)  
- **删除堆顶（Extract Max）**：O(log n)  
- **建堆（Heapify）**：O(n)（从无序数组构建堆的优化操作）  

---

### **四、堆排序中的大顶堆**
堆排序利用大顶堆的堆顶元素为最大值的特性，分为两步：  
1. **建堆**：将无序数组调整为一个大顶堆。  
2. **排序**：  
   - 交换堆顶（最大值）与当前未排序部分的末尾元素。  
   - 缩小堆的范围，重新调整剩余元素为大顶堆。  
   - 重复直到所有元素有序。  

**堆排序流程示例**（以数组 `[3, 1, 4, 1, 5, 9, 2, 6]` 为例）：  
```
初始数组：3 1 4 1 5 9 2 6  
建堆后：9 6 4 3 5 1 2 1  
排序过程：  
交换堆顶9和末尾1 → 调整剩余部分为大顶堆 → 重复直到有序。
```

### **五、堆与其他数据结构的对比**
| 数据结构   | 特点                                                                 | 典型应用场景               |
|------------|----------------------------------------------------------------------|---------------------------|
| 堆         | 快速获取最大值/最小值（O(1)），插入删除高效（O(log n)）              | 堆排序、优先队列、Top K问题 |
| 二叉搜索树 | 中序遍历有序，查找/插入/删除平均O(log n)（可能退化为链表）           | 动态数据的有序存储         |
| 数组       | 随机访问O(1)，插入删除O(n)                                           | 静态数据存储               |

### **六、代码实现堆调整（以大顶堆为例）**
```python
def heapify(arr, n, i):
    largest = i         # 当前节点索引
    left = 2 * i + 1    # 左子节点索引
    right = 2 * i + 2   # 右子节点索引

    # 找到当前节点、左子节点、右子节点中的最大值
    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right

    # 如果最大值不是当前节点，交换并递归调整
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)  # 递归调整受影响的子树

def build_max_heap(arr):
    n = len(arr)
    # 从最后一个非叶子节点开始反向调整
    for i in range(n//2 - 1, -1, -1):
        heapify(arr, n, i)
```

### **七、总结**
- **大顶堆**是堆排序的核心，通过不断提取堆顶最大值完成排序。  
- **堆的特点**：  
  - 完全二叉树结构，数组存储高效。  
  - 父节点与子节点的有序性（大顶堆/小顶堆）。  
  - 适合动态维护最大值或最小值（如优先队列）。
