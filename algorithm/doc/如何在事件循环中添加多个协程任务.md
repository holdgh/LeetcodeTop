在 Python 的异步编程中，通过事件循环管理和并发执行多个协程任务的核心方法如下：

---

### **方法一：使用 `asyncio.gather()` 批量提交任务**
**适用场景**：需要并发执行多个协程，并统一处理结果或异常。
```python
import asyncio

async def task1():
    await asyncio.sleep(1)
    print("Task 1 完成")
    return "结果1"

async def task2():
    await asyncio.sleep(2)
    print("Task 2 完成")
    return "结果2"

async def main():
    # 批量提交任务并等待结果
    results = await asyncio.gather(task1(), task2())
    print("所有任务结果:", results)  # 输出: ['结果1', '结果2']

asyncio.run(main())
```
**输出**：
```
Task 1 完成
Task 2 完成
所有任务结果: ['结果1', '结果2']
```

---

### **方法二：手动创建并管理多个 `Task` 对象**
**适用场景**：需要更精细控制任务（如动态添加、取消等）。
```python
import asyncio

async def task(num):
    print(f"任务 {num} 开始")
    await asyncio.sleep(1)
    print(f"任务 {num} 结束")
    return f"结果{num}"

async def main():
    # 创建并启动多个任务
    task_a = asyncio.create_task(task(1))
    task_b = asyncio.create_task(task(2))
    
    # 等待任务完成并获取结果
    result_a = await task_a
    result_b = await task_b
    print("任务结果:", result_a, result_b)

asyncio.run(main())
```
**输出**：
```
任务 1 开始
任务 2 开始
任务 1 结束
任务 2 结束
任务结果: 结果1 结果2
```

---

### **方法三：动态添加任务到运行中的事件循环**
**适用场景**：在事件循环运行过程中动态添加新任务（如响应外部事件）。
```python
import asyncio

async def background_task():
    while True:
        print("后台任务运行中...")
        await asyncio.sleep(2)

async def main():
    # 启动一个后台任务
    asyncio.create_task(background_task())
    
    # 动态添加一次性任务
    await asyncio.sleep(1)
    asyncio.create_task(print("动态添加的任务执行了！"))
    
    # 保持事件循环运行
    await asyncio.sleep(5)

asyncio.run(main())
```
**输出**：
```
后台任务运行中...
动态添加的任务执行了！
后台任务运行中...
后台任务运行中...
```

---

### **方法四：使用队列（`asyncio.Queue`）控制任务并发**
**适用场景**：生产者-消费者模型，限制同时运行的任务数量。
```python
import asyncio

async def worker(queue):
    while True:
        task_id = await queue.get()
        print(f"处理任务 {task_id}")
        await asyncio.sleep(1)
        queue.task_done()

async def main():
    queue = asyncio.Queue()
    
    # 启动3个消费者协程
    workers = [asyncio.create_task(worker(queue)) for _ in range(3)]
    
    # 生产者添加10个任务
    for i in range(10):
        await queue.put(i)
    
    # 等待所有任务完成
    await queue.join()
    
    # 取消消费者协程
    for w in workers:
        w.cancel()

asyncio.run(main())
```
**输出**：
```
处理任务 0
处理任务 1
处理任务 2
处理任务 3
处理任务 4
处理任务 5
...（每秒处理3个任务）
```

---

### **关键注意事项**
1. **任务创建与启动**  
   - 使用 `asyncio.create_task()` 或 `loop.create_task()` 将协程包装为 `Task`，立即加入事件循环。
   - 直接调用协程函数（如 `task()`）不会执行，需显式提交。

2. **错误处理**  
   - 在 `asyncio.gather()` 中使用 `return_exceptions=True` 捕获异常：
     ```python
     results = await asyncio.gather(task1(), task2(), return_exceptions=True)
     ```

3. **资源限制**  
   - 使用 `asyncio.Semaphore` 限制并发数：
     ```python
     sem = asyncio.Semaphore(3)
     async def limited_task():
         async with sem:
             await asyncio.sleep(1)
     ```

---

### **总结**
| **方法**               | **适用场景**                           | **优点**                          | **缺点**                  |
|------------------------|---------------------------------------|-----------------------------------|---------------------------|
| **`asyncio.gather()`** | 批量执行任务，统一处理结果             | 代码简洁，结果顺序固定            | 无法动态添加任务          |
| **手动管理 `Task`**    | 需要精细控制任务生命周期              | 灵活性高                          | 代码稍复杂                |
| **动态添加任务**       | 运行时按需生成任务（如事件驱动）       | 高度灵活                          | 需注意任务清理            |
| **任务队列**           | 生产者-消费者模型，控制并发度          | 资源管理方便                      | 需要额外队列管理逻辑      |

根据具体需求选择合适的方法，合理利用事件循环的并发能力，可以显著提升 I/O 密集型应用的性能。
